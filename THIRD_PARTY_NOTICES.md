# Third-party notices

## FaithfulVenom 32x

MinePrompt includes a focused graphical asset set from FaithfulVenom 32x. The source is the FaithfulVenom 1.21 branch at commit `8a23f40686acc2985267be251323337c032d369e`:

https://github.com/mullak99s-Faithful/FaithfulVenom

The bundled set contains the item, block, status effect, player inventory, container slot, health, hunger, armor, air, experience, hotbar, boss bar, tooltip, and workstation textures used by the session interface. It includes compatible asset overrides through Minecraft 1.21.11. Block and shield textures are transformed at runtime into item-scale graphical previews.

FaithfulVenom is maintained by mullak99. Its textures include work from AntVenom, Vattic, Classic Faithful, the Faithful Team, mullak99, and the additional creators recorded by the resource pack.

The original license and detailed texture credits are included without modification in [third_party/FaithfulVenom/License.txt](third_party/FaithfulVenom/License.txt) and [third_party/FaithfulVenom/Credits.txt](third_party/FaithfulVenom/Credits.txt). The asset license prohibits monetizing content that contains this work. MinePrompt is not an official FaithfulVenom or Faithful Resource Pack project.
